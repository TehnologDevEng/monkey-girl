# 🚗 Ноябрьск: Экзамен ГИБДД — Интерактивный тренажер и карта

Интерактивное веб-приложение для подготовки к практическому экзамену ГИБДД в городе **Ноябрьск (ЯНАО)**.

На карте отмечены:
- 🛑 **Более 130 реальных дорожных знаков ГОСТ** по всему городу (пр. Мира, ул. Ленина, Советская, Холмогорская, 40 лет Победы, Дзержинского, Цоя, Шевченко, Космонавтов, Киевская, Республики, Изыскателей, Магистральная и др.).
- ⚠️ **Ловушки инспекторов ГИБДД** с подробными подсказками инструктора и штрафными баллами по регламенту.
- 🚦 **Сложные перекрёстки** с правилами разъезда и круговым движением.
- 🏎️ **Зоны ограничения скорости** (20, 40, 60 км/ч).
- 🛣️ **Экзаменационные маршруты** автошколы (пр. Мира 83).
- 📝 **Блокнот курсанта** с сохранением пользовательских меток и заметок в `localStorage`.
- 🎓 **Квиз-тренажер** на знание реальных дорожных ситуаций Ноябрьска.

## 🚀 Быстрый запуск на GitHub Pages

Проект полностью оптимизирован для работы на **GitHub Pages** (используются относительные пути `./` в сборке Vite).

### Вариант 1: Автоматический деплой через GitHub Actions (Рекомендуется)
1. Загрузите репозиторий на GitHub (`main` или `master`).
2. В репозитории на GitHub перейдите в:  
   **Settings** ➔ **Pages** (в боковом меню).
3. В пункте **Build and deployment** выберите **Source**: `GitHub Actions`.
4. Готово! При каждом пуше в ветку `main` проект будет автоматически собираться и публиковаться по адресу:  
   `https://<ваш-логин>.github.io/<имя-репозитория>/`

### Вариант 2: Локальная сборка
Если вы хотите вручную собрать проект в папку `dist`:
```bash
npm install
npm run build
```
Содержимое папки `dist/` можно залить на любой статический хостинг (GitHub Pages, Vercel, Netlify, Timeweb и др.).

## 💻 Локальная разработка

### Требования
- **Node.js** версии 18 или новее
- **npm** (поставляется вместе с Node.js)

### Установка и запуск
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/<ваш-логин>/<имя-репозитория>.git
   cd <имя-репозитория>
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```

4. Откройте в браузере: `http://localhost:3000`
